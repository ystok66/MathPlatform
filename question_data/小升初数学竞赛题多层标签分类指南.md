# 小升初数学竞赛题多层标签分类指南

## AI Agent 题目归类规范

## 一、任务目标

当输入一道中国小学高年级，尤其是五、六年级及小升初阶段的数学竞赛题时，AI Agent 应分析题目的数学结构、核心知识、典型模型和主要解法，并为题目生成一组规范化标签。

本分类系统采用：

> **一个主分类路径＋若干辅助分类路径＋多个方法标签＋题目任务标签**

标签允许：

- 多层级；
- 多标签；
- 一个主标签和多个次标签；
- 同一道题同时涉及多个知识模块；
- 同一道题使用多种解题方法。

暂不评价题目难度，不输出“简单、中等、困难”等难度标签。

------

# 二、基本分类原则

## 1. 根据数学本质分类，不根据故事表面分类

不能仅根据题目中出现的词语判断类别。

例如：

- 题目出现“商店”，不一定就是经济问题；
- 题目出现“圆形跑道”，不一定就是几何题；
- 题目出现“平均”，不一定就是平均数问题；
- 题目出现“余数”，不一定以余数问题为主；
- 题目要求“列方程”，不代表它属于代数题。

应先判断解决题目时真正需要识别的数学模型。

例如：

> 甲、乙两人在圆形跑道上同时出发，求第几次相遇。

虽然题目中有圆形图形，但核心是速度、时间、路程和周期，因此主分类通常为：

```text
应用题 → 行程问题 → 环形跑道问题
```

可以附加：

```text
辅助知识：周期规律
方法：相对速度、最小公倍数
```

------

## 2. 先形成最简解题思路，再确定标签

AI Agent 不应只做关键词匹配。

在分类前，应先在内部完成以下判断：

1. 已知量是什么；
2. 未知量是什么；
3. 核心数量关系是什么；
4. 题目最关键的突破点是什么；
5. 至少需要哪些知识才能完成；
6. 哪种方法决定了题目能否被解决。

不要求输出完整解答，但必须基于一个可信的解题思路进行分类。

------

## 3. 主分类由“核心障碍”决定

一道题可能涉及很多知识，但主分类应对应：

> 如果学生不会这个知识或模型，就最难完成题目的部分。

例如：

> 用数字1、2、3、4组成没有重复数字的四位数，其中有多少个能被3整除？

题目同时涉及排列与整除。

如果判断整除性后主要任务是统计排列数，则可标为：

```text
主分类：计数与组合 → 排列问题 → 有限制排列
辅助分类：数论 → 整除特征 → 3的整除特征
```

如果题目重点是寻找满足复杂整除条件的数字，而计数只是简单枚举，则可以反过来：

```text
主分类：数论 → 数字与数位 → 数字排列与整除
辅助分类：计数与组合 → 分类枚举
```

------

## 4. 区分知识标签和方法标签

“研究什么”与“怎样解决”必须分开。

例如：

> 一个数除以3余1，除以5余2，求最小的这个数。

知识标签：

```text
数论 → 余数问题 → 多条件余数
```

方法标签可以是：

```text
枚举法
同余转化
逐步筛选
```

不能把“枚举法”放进知识分类路径，也不能只输出“枚举法”而不说明题目属于余数问题。

------

## 5. 必要知识才标注，偶然出现的知识不标注

若某个知识只用于最后一步普通计算，不构成题目结构，则不应标为独立知识标签。

例如：

> 一道工程问题最后需要计算两个分数的加法。

不需要因为出现分数运算就添加：

```text
计算与运算 → 分数运算
```

除非分数计算本身具有特殊技巧，并且是题目的主要难点之一。

------

## 6. 使用最细但可靠的标签

应尽量标到能够确定的最细层级。

例如，不要只标：

```text
应用题
```

而应尽量标为：

```text
应用题 → 行程问题 → 流水行船
```

但是，如果题目信息不足，不能凭空猜测更细分类。

例如，只知道题目“与速度有关”，但无法判断是追及还是相遇，则可以标：

```text
应用题 → 行程问题
```

不要强行标为：

```text
应用题 → 行程问题 → 追及问题
```

------

# 三、标签整体结构

每道题建议包含以下六组标签。

## 1. 主分类路径 `primary_path`

必须有且原则上只有一条。

格式：

```text
一级类别 → 二级类别 → 三级模型
```

例如：

```text
数论 → 余数问题 → 幂的周期余数
```

------

## 2. 辅助分类路径 `secondary_paths`

记录题目中另外必须使用的重要知识。

一般为0至3条。

例如：

```text
代数与规律 → 周期规律
计数与组合 → 分类枚举
```

辅助分类必须对解题有实质作用，不能为了增加标签数量而过度标注。

------

## 3. 方法标签 `method_tags`

记录实际有效的解题方法。

例如：

```text
裂项消项
方程法
倒推法
分类讨论
割补法
抽屉原理
不变量法
```

一般选择1至4个最关键的方法。

------

## 4. 任务标签 `task_tags`

记录题目要求学生完成什么。

例如：

```text
求值
求未知数
求个数
求最小值
求最大值
求取值范围
判断
证明
构造
方案设计
规律预测
反推原量
```

------

## 5. 结构标签 `structure_tags`

记录题目的呈现和组织形式。

可选标签包括：

```text
纯计算式
文字应用题
图形题
表格信息题
统计图题
数阵题
操作题
多步骤题
多问综合题
开放题
新定义题
```

------

## 6. 条件标签 `constraint_tags`

记录对答案空间有明显影响的条件。

例如：

```text
正整数
自然数
各不相同
允许重复
不允许重复
最小正整数
整除条件
余数条件
范围限制
相邻限制
顺序限制
至少
至多
恰好
必然存在
不可能存在
```

这些标签不能替代知识标签，只用于描述题目限制。

# 十四、主次标签判定规则

## 规则一：标准模型优先

若题目符合一个成熟、稳定、明确的标准模型，应以该模型为主分类。

例如：

- 合作完成工作：工程问题；
- 顺流逆流：流水行船；
- 时针分针夹角：时钟问题；
- 溶液加水：浓度问题；
- 若干人分物品有盈有亏：盈亏问题。

即使使用方程求解，也不应把主分类改为方程。

------

## 规则二：知识决定可行性，方法决定效率

若不会某知识就无法完成题目，该知识应进入主分类或辅助分类。

若某方法只是让解答更简洁，可以只作为方法标签。

例如：

> 求 (7^{2026}) 的个位数字。

应标为：

```text
主分类：数论 → 周期与末位数字 → 个位数字周期
方法：周期法、同余法
任务：求值
```

不能只标：

```text
方法：枚举
```

------

## 规则三：问“多少种”不一定属于计数题

题目要求“有多少种”只是任务形式。

只有当“不重不漏地统计方案”是核心时，才以计数与组合为主分类。

例如：

> 方程 (3x+5y=30) 有多少组正整数解？

主分类可以是：

```text
数论 → 不定方程与整数解 → 正整数解个数
```

辅助分类：

```text
计数与组合 → 分类枚举
```

因为核心首先是整数解结构，而不是普通排列组合。

------

## 规则四：含图形不一定是几何题

若图形只是帮助呈现排列、路线或逻辑关系，不一定以几何为主。

例如：

> 在方格中从左下角走到右上角，每次只能向右或向上，共有多少条最短路线？

主分类：

```text
计数、组合与概率 → 路线与网络计数 → 网格最短路线
```

结构标签：

```text
图形题
```

而不是：

```text
几何 → 方格与坐标
```

------

## 规则五：周期问题按周期来源分类

### 数论周期

例如：

- 幂的个位数；
- 余数循环；
- 数字末位。

分类：

```text
数论 → 周期与末位数字
```

### 数列或图形周期

例如：

- 红黄蓝循环排列；
- 图案按四个一组重复。

分类：

```text
代数与规律 → 周期规律
```

### 运动周期

例如：

- 环形跑道再次相遇；
- 多个事件再次同时发生。

主分类通常是：

```text
应用题 → 环形跑道
```

或：

```text
数论 → 最大公因数与最小公倍数 → 周期重合
```

根据题目的主要建模过程决定。

------

## 规则六：新定义题不必全部归入综合创新

若新定义只是把普通运算换了符号，例如：

[
a*b=2a+b
]

通常分类为：

```text
计算与运算 → 定义新运算
```

若新定义形成一个复杂系统，需要研究其性质、构造对象或证明结论，则可以归为：

```text
综合与创新 → 新定义阅读题
```

------

## 规则七：几何计数与组合计数的区分

### 以几何识别为核心

例如数复杂图形中有多少个三角形：

```text
主分类：几何 → 几何计数 → 数三角形
辅助分类：计数与组合 → 分类枚举
```

### 以选择和排列为核心

例如从若干点中选择三个点组成三角形：

```text
主分类：计数、组合与概率 → 组合问题
辅助分类：几何 → 三角形
```

------

## 规则八：综合题不能滥用

满足下列情况之一，才考虑使用“多模块综合题”：

1. 两个以上模块地位接近；
2. 无法仅靠一个标准模型描述；
3. 解题必须在多个模块之间反复转换；
4. 题目本身要求综合证明、构造或探索。

仅仅因为工程题中出现分数，不能标为综合题。

------

# 十五、标签数量控制

为了避免过度标注，推荐采用以下限制：

```text
主分类路径：1条
辅助分类路径：0至3条
方法标签：1至4个
任务标签：1至3个
结构标签：0至3个
条件标签：0至6个
```

若输出超过这些数量，应检查是否把偶然出现的知识也错误标注了。

# 十六、AI Agent 分类流程

AI Agent 应按照以下顺序执行。

## 第一步：识别题目任务

判断题目要求：

- 求数值；
- 求未知数；
- 求方案数；
- 求最大值或最小值；
- 判断真假；
- 证明结论；
- 构造对象；
- 设计方案。

生成任务标签。

------

## 第二步：识别数学对象

判断题目主要研究：

- 数和算式；
- 整数性质；
- 数量关系；
- 实际应用模型；
- 平面图形；
- 立体图形；
- 排列与选择；
- 逻辑陈述；
- 操作过程；
- 新定义系统。

由此确定一级分类候选。

------

## 第三步：建立最简解题路径

在内部形成简要解题框架，例如：

```text
先根据3的整除特征筛选数字，再统计符合条件的排列。
```

或者：

```text
先求甲乙相对速度，再利用路程差求追及时间。
```

------

## 第四步：确定核心障碍

判断：

> 解题过程中，哪一个知识或模型最具有决定性？

将其设为主分类路径。

------

## 第五步：添加辅助分类

只有当另一个知识满足以下条件时才添加：

- 不使用它无法完成；
- 它承担了独立的一段推理；
- 它不是普通计算；
- 它不是仅由主模型自然包含的基础步骤。

------

## 第六步：添加方法标签

根据实际解法选择最关键的方法。

不能仅根据题目“可能可以使用”某方法，就添加该标签。

------

## 第七步：添加结构和条件标签

标记题目呈现形式和明显约束。

------

## 第八步：检查标签一致性

检查以下问题：

1. 主分类是否只有一个；
2. 是否标到了足够具体的层级；
3. 是否把方法误作知识类别；
4. 是否把故事背景误作主分类；
5. 是否存在无关标签；
6. 主次标签是否颠倒；
7. 是否错误使用“综合题”；
8. 是否遗漏题目的核心限制。

------

```text
主分类：数论 → 不定方程与整数解 → 正整数解
辅助分类：计数、组合与概率 → 分类枚举
方法：同余法、枚举整数解
任务：求个数
条件：正整数
```

# 二十、最终执行要求

AI Agent 对每道题进行分类时，应遵守以下最终要求：

1. 必须输出一条主分类路径；
2. 主分类必须反映题目的数学核心；
3. 允许输出多个辅助知识标签；
4. 知识标签与方法标签必须分开；
5. 不得根据故事关键词机械分类；
6. 不得把普通计算步骤全部标成辅助知识；
7. 不得滥用“综合题”标签；
8. 不得输出难度等级；
9. 不确定时应给出候选分类和分类依据；
10. 分类依据应简洁说明“为什么这样归类”，而不是输出完整解题过程；
11. 标签名称应优先从本指南的规范词表中选择；
12. 若现有标签确实无法覆盖，可创建新三级标签，但原则上不创建新的一级分类；
13. 新标签应保持简洁、明确，并与同层标签粒度一致；
14. 同一批题目必须使用一致的标签名称，不能交替使用同义标签。

推荐最终输出顺序为：

```text
主分类
辅助分类
方法标签
任务标签
结构标签
条件标签
分类依据
分类置信度
```
