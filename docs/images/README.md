local demonstration runtime. Screenshots are documentation assets, not test
results or proof of model quality. No paid AI request was made for this capture.

for the demonstration practice session.

## Interpretation and limitations

- Existing imported questions keep their source language; some are Chinese.
- Screenshots reflect the captured build and are not a guarantee about later UI revisions.
- No browser DOM, task status, model output, or learning metric was altered to make screenshots.
- Some screenshots are cropped to the relevant workspace; long screenshots are folded in the README.
- UI capture does not replace functional tests, accessibility checks, or release readiness checks.
- Native macOS packages were not built or tested by this documentation task.
- Existing ZIP archives are an earlier snapshot until the next release finalization.
